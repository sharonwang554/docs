This page details the Contentful content types used to manage the site's data. Each section specifies the Contentful ID, TS interface, consuming route, and a breakdown of all fields.

## Site Info
- **Content Type ID:** `siteInfo`
- **TS Interface:** `ContentfulSiteInfo` / `SiteInfo`
- **Consuming Route:** Global Layout (All pages)
- **Description:** Global site information such as church name, contact info, and social links.

| Field Name | Type | Localized | Required | Notes |
|---|---|---|---|---|
| `name` | Short text | Yes | Yes | Short name (e.g. 左營復活堂) |
| `nameEn` | Short text | No | Yes | English short name (e.g. Raised Church) |
| `fullName` | Short text | Yes | Yes | Full localized name |
| `fullNameEn` | Short text | No | Yes | Full English name |
| `address` | Short text | Yes | Yes | Localized address |
| `addressEn` | Short text | No | Yes | English address |
| `phone` | Short text | No | Yes | Contact phone number |
| `fax` | Short text | No | No | Fax number |
| `email` | Short text | No | No | Contact email |
| `facebookUrl` | Short text | No | No | Facebook page link |
| `lineUrl` | Short text | No | No | Line official account link |
| `youtubeUrl` | Short text | No | No | YouTube channel link |
| `youtubeLiveStreamUrl` | Short text | No | No | Link to the Sunday live stream |
| `mapEmbedUrl` | Long text | No | Yes | Google Maps `iframe` `src` URL |

## News Banner
- **Content Type ID:** `newsBanner`
- **TS Interface:** `ContentfulNewsBanner` / `NewsBanner`
- **Consuming Route:** Global Layout
- **Description:** An alert banner that displays at the top of the site.

| Field Name | Type | Localized | Required | Notes |
|---|---|---|---|---|
| `isActive` | Boolean | No | Yes | Toggles the banner display |
| `message` | Short text | Yes | Yes | The alert text |
| `linkUrl` | Short text | No | No | Optional URL for the call-to-action |
| `linkText` | Short text | Yes | No | The button text if `linkUrl` is present |

## Church News
- **Content Type ID:** `churchNews`
- **TS Interface:** `ContentfulChurchNewsItem` / `ChurchNewsItem`
- **Consuming Route:** `/`, `/events`
- **Description:** Upcoming events and text announcements.

| Field Name | Type | Localized | Required | Notes |
|---|---|---|---|---|
| `title` | Short text | Yes | Yes | Announcement or event title |
| `type` | Short text | No | Yes | Validation: `announcement` or `event` |
| `date` | Date & time | No | No | Required if type is `event` |
| `location` | Short text | Yes | No | Location of the event |
| `body` | Long text | Yes | Yes | Main description |
| `signUpUrl` | Short text | No | No | External registration link (e.g., Google Forms) |
| `signUpDeadline` | Date | No | No | Deadline for registration |
| `image` | Media | No | No | Optional cover image |
| `isActive` | Boolean | No | Yes | Toggles visibility of the item |
