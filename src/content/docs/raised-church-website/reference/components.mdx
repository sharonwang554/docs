This page provides a dictionary of all Svelte components located in `src/lib/components/`. All components are written using Svelte 5 runes (`$props()`, `$derived()`).

## Layout

### `Footer.svelte`
- **Path:** `src/lib/components/Footer.svelte`
- **Props:** None (derives data from `$app/state`)
- **Description:** Renders the global site footer, including contact information and social links.
- **Usage:** `<Footer />`

### `Navbar.svelte`
- **Path:** `src/lib/components/Navbar.svelte`
- **Props:** None (derives data from `$app/state`)
- **Description:** Main navigation bar, handling mobile toggles, language switching, and dropdowns.
- **Usage:** `<Navbar />`

### `NavBrand.svelte`
- **Path:** `src/lib/components/NavBrand.svelte`
- **Props:**
  ```typescript
  let { lang, onclick }: { lang: Language; onclick: () => void } = $props();
  ```
- **Description:** Renders the church logo and name in the navigation bar.
- **Usage:** `<NavBrand lang="zh" onclick={closeMenu} />`

### `MobileMenu.svelte`
- **Path:** `src/lib/components/MobileMenu.svelte`
- **Props:**
  ```typescript
  let { isOpen, toggle, close, children }: { 
    isOpen: boolean; 
    toggle: () => void; 
    close: () => void;
    children: import('svelte').Snippet;
  } = $props();
  ```
- **Description:** A wrapper component for the mobile navigation drawer.
- **Usage:** `<MobileMenu {isOpen} {toggle} {close}>...</MobileMenu>`

### `ErrorBoundary.svelte`
- **Path:** `src/lib/components/ErrorBoundary.svelte`
- **Props:**
  ```typescript
  let { error, retry }: {
    error?: { message: string; code?: string };
    retry?: () => void;
  } = $props();
  ```
- **Description:** Displays a localized error fallback UI when data loading or rendering fails.
- **Usage:** `<ErrorBoundary error={e} retry={fetchData} />`

## Navigation

### `NavLink.svelte`
- **Path:** `src/lib/components/NavLink.svelte`
- **Props:**
  ```typescript
  let { item, lang, isActive, closeMobile, isExpanded = false, onToggle }: { 
    item: NavItem; 
    lang: Language; 
    isActive: (href: string) => boolean; 
    closeMobile: () => void;
    isExpanded?: boolean;
    onToggle?: () => void;
  } = $props();
  ```
- **Description:** A single navigation link, with support for nested dropdown menus.
- **Usage:** `<NavLink {item} {lang} {isActive} {closeMobile} />`

### `Breadcrumb.svelte`
- **Path:** `src/lib/components/Breadcrumb.svelte`
- **Props:**
  ```typescript
  let { items, lang = "zh" }: {
    items: Array<{ name: string; url: string }>;
    lang?: string;
  } = $props();
  ```
- **Description:** Generates breadcrumb navigation and automatically embeds JSON-LD structured data for SEO.
- **Usage:** `<Breadcrumb items={[{ name: "Home", url: "/" }]} />`

### `Pagination.svelte`
- **Path:** `src/lib/components/Pagination.svelte`
- **Props:**
  ```typescript
  let { currentPage = 1, totalPages = 1, onPageChange }: {
    currentPage: number;
    totalPages: number;
    onPageChange: (page: number) => void;
  } = $props();
  ```
- **Description:** Displays pagination controls (next, previous, page numbers) for lists.
- **Usage:** `<Pagination currentPage={2} totalPages={5} onPageChange={goToPage} />`

## Content

## SEO

### `SEOHead.svelte`
- **Path:** `src/lib/components/SEOHead.svelte`
- **Props:**
  ```typescript
  let { title = "", description = "", keywords = "", ogImage = "/og-image.png", ogType = "website", canonical = "", lang = "zh", pathname = "" }: {
    title?: string;
    description?: string;
    keywords?: string;
    ogImage?: string;
    ogType?: string;
    canonical?: string;
    lang?: string;
    pathname?: string;
  } = $props();
  ```
