# Component Reference Guide

## Overview

The project includes 12 reusable Svelte 5 components. Each component follows these principles:
- Props defined with `$props()` rune and explicit TypeScript types
- Reactive state with `$state()` for mutable values
- Derived values with `$derived()` for computed properties
- SCSS styling with autoinjected shared variables
- Accessibility support (ARIA labels, semantic HTML)

## Core Components

### HeroSlider
**Purpose:** Carousel/slideshow for hero images with autoplay, manual controls, and accessibility.

**Location:** `src/lib/components/HeroSlider.svelte`

**Props:**
```typescript
interface Slide {
  src: string;      // Image URL
  alt: string;      // Alt text for accessibility
}

let {
  slides = [] as Slide[],
  autoplayInterval = 5000,  // ms between slides
  height = "70vh,"          // CSS height
  lang = "zh,"              // Language for labels
} = $props();
```

**Features:**
- Autoadvances slides every 5 seconds (pause on hover)
- Arrow buttons and dot indicators for navigation
- Keyboard accessible
- ARIA labels for screen readers
- Responsive sizing with clamp()
- Smooth transitions with opacity & scale

**Usage Example:**
```svelte
<HeroSlider 
  slides={[
    { src: "image1.jpg," alt: "Church gathering" },
    { src: "image2.jpg," alt: "Worship" }
  ]}
  autoplayInterval={6000}
  height="60vh"
  lang={page.params.lang}
/>
```

**Accessibility:**
- `aria-label` on each slide (for example, "第 1 張，共 3 張")
- `aria-roledescription="carousel"` on container
- `aria-selected` on active dot indicator
- Keyboard navigation: Tab to focus, Enter/Space to activate

**State Management:**
- `currentIndex` - which slide is active
- `paused` - whether autoplay is paused (hover)
- `timer` - reference to setInterval for cleanup

### ContactForm
**Purpose:** Web3Forms integration for contact form submissions with error handling.

**Location:** `src/lib/components/ContactForm.svelte`

**Props:** None (uses `$page.data` internally)

**Dependencies:**
- `$page` from `$app/state` - for site data
- `PUBLIC_WEB3FORMS` environment variable

**Features:**
- Name, email, message fields
- Autosubmit via Web3Forms API
- Status feedback (idle, submitting, success, error)
- Autodismiss messages after delay
- i18n support for labels and messages
- Embedded Google Maps iframe

**Form States:**
```typescript
type FormStatus = "idle" | "submitting" | "success" | "error";
```

**Error Handling:**
- Network errors → generic message
- API errors → server error message
- Client-side validation (built-in HTML5)

**Usage Example:**
```svelte
<ContactForm />
```

**Note:** Form requires:
1. `PUBLIC_WEB3FORMS` in `.env`
2. `$page.data.siteInfo` with `mapEmbedUrl` from Contentful
3. Valid locale (autodetects from language)

**Styling Notes:**
- `.contact__layout` uses CSS Grid for responsive design
- Map and form side-by-side on desktop, stacked on mobile

### Pagination
**Purpose:** Pagination controls for lists with multiple pages.

**Location:** `src/lib/components/Pagination.svelte`

**Props:**
```typescript
let {
  currentPage = 1,
  totalPages = 1,
  onPageChange,
}: {
  currentPage: number;
  totalPages: number;
  onPageChange: (page: number) => void;
} = $props();
```

**Features:**
- Previous/Next buttons
- Page number buttons
- Ellipsis for skipped pages
- Accessibility: ARIA labels, semantic nav
- Responsive: shows fewer buttons on mobile

**Visible Pages Logic:**
Shows current page ± 2 pages, always shows page 1 and last page.

**Example:**
```
< 1 ... 4 5 [6] 7 8 ... 12 >
```

**Usage Example:**
```svelte
<Pagination 
  currentPage={currentPage}
  totalPages={totalPages}
  onPageChange={(page) => {
    currentPage = page;
    // Fetch data for new page
  }}
/>
```

## Component Props Pattern (Svelte 5)

All components use the `$props()` rune:

```svelte
<script lang="ts">
  interface Props {
    title: string;
    description?: string;
    count: number;
  }
  
  let { title, description, count }: Props = $props();
</script>
```

## Styling Components

All components autoinject `src/lib/styles/_shared.scss` which includes:

```scss
// Colors

$color-text
$color-white
$color-bg

// Spacing
$space-sm, $space-md, $space-lg, $space-xl

// Typography
$font-heading
$font-body
$font-size-*

// Utilities
$breakpoint-*
@mixin flex-center
@mixin focus-ring
```

### BEM Naming Convention
Components use BEM (Block-Element-Modifier):

```scss
.navbar {}              // Block
.navbar__link {}        // Element
.navbar__link--active   // Modifier
```

### Scoped Styles
All component styles are scoped by default (Svelte feature).

## Lifecycle & Cleanup

Components using event listeners must clean up:

```svelte
<script>
  import { onMount, onDestroy } from "svelte";
  
  let timer;
  
  onMount(() => {
    window.addEventListener("scroll," handleScroll);
    timer = setInterval(() => {}, 5000);
  });
  
  onDestroy(() => {
    window.removeEventListener("scroll," handleScroll);
    clearInterval(timer);
  });
</script>
```

## Accessibility Checklist

When creating components, ensure:
- [ ] Semantic HTML (`<button>`, `<nav>`, `<main>`)
- [ ] ARIA labels where needed
- [ ] Keyboard navigation (Tab, Enter, Escape)
- [ ] Color contrast >= 4.5:1
- [ ] Text alternatives for images
- [ ] Focus indicators visible

## Common Issues

### Component Not Receiving Props
- Check prop destructuring in `$props()`
- Verify parent is passing correct prop names
- Use TypeScript for autocomplete

### Styles Not Applying
- Component styles are scoped; use `.` for global scope if needed
- Check SCSS variable names
- Verify class names match

### Event Listeners Not Cleaning Up
- Always `onDestroy()` listeners and timers
- Check Svelte 5 lifecycle vs. Svelte 4 patterns

### i18n Not Working
- Use `page.params.lang` to get current language
- Use `getTranslation(lang)` helper function
- Ensure translation keys exist in `src/lib/i18n/index.ts`
