This tutorial guides you through the process of adding a new feature to the Raised Church website. You build a "Gallery" page end-to-end, which involves routing, server-side data loading, Svelte 5 components, internationalization (i18n), and SCSS styling.

## Plan the page

Before writing code, plan out what the page requires:

- **Route**: `src/routes/[[lang]]/gallery/` (supports optional `/en` prefix for English)
- **Data**: Server-side loading of a gallery title, description, and an array of images
- **Components**: A layout using `$props()` to receive the data and render a responsive grid

<Steps>

1.  **Create the route directory**

    Create a new directory for the gallery route. The `[[lang]]` parameter handles bilingual routing automatically.

    ```bash
    mkdir -p 'src/routes/[[lang]]/gallery'
    ```

2.  **Create the server-side load function**

    Create `src/routes/[[lang]]/gallery/+page.server.ts`. The `ContentRepository` pattern abstracts away the data source. This allows the application to seamlessly switch between Contentful and local JSON fallbacks based on environment configuration.

    ```typescript
    import { getContentRepository } from "$lib/server/content-repository";
    import type { PageServerLoad } from "./$types";

    export const load: PageServerLoad = async ({ params }) => {
      const lang = params.lang as "en" | "zh" | undefined;
      const repo = getContentRepository();
      
      const galleryData = await repo.fetchGallery(lang);
      
      return { ...galleryData };
    };
    ```

3.  **Create the page component**

    Create `src/routes/[[lang]]/gallery/+page.svelte`. The `$derived()` rune ensures that the interface updates automatically when users switch the active language.

    ```svelte
    <script lang="ts">
      import { page } from "$app/state";
      import { getTranslation, getLangFromParams } from "$lib/i18n";
      
      let { data } = $props();
      
      let lang = $derived(getLangFromParams(page.params));
      let t = $derived(getTranslation(lang));
    </script>

    <div class="gallery-container">
      <header>
        <h1>{t.pages.gallery.title}</h1>
        <p>{t.pages.gallery.subtitle}</p>
      </header>

      <div class="image-grid">
        {#each data.images as image}
          <div class="image-card">
            <img src={image.url} alt={image.alt} loading="lazy" />
          </div>
        {/each}
      </div>
    </div>

    <style lang="scss">
      @use '$lib/styles/shared' as *;

      .gallery-container {
        padding: $space-lg;
        max-width: 1200px;
        margin: 0 auto;
      }

      .image-grid {
        display: grid;
        grid-template-columns: repeat(auto-fill, minmax(300px, 1fr));
        gap: $space-md;
        margin-top: $space-xl;
      }

      .image-card {
        border-radius: $radius-md;
        overflow: hidden;
        box-shadow: $shadow-sm;

        img {
          width: 100%;
          height: 100%;
          object-fit: cover;
          transition: transform $transition-base;
          
          &:hover {
            transform: scale(1.05);
          }
        }
      }
    </style>
    ```

4.  **Add translations to the dictionary**

    Add strings for the gallery page to `src/lib/i18n/index.ts`. Defining strings in a central dictionary keeps UI text consistent and simplifies adding new languages later.

    ```typescript
    // In the zh (Chinese) section
    pages: {
      // ... existing pages
      gallery: {
        title: "活動相冊",
        subtitle: "教會生活點滴",
      },
    }

    // In the en (English) section
    pages: {
      // ... existing pages
      gallery: {
        title: "Gallery",
        subtitle: "Moments from our church life",
      },
    }
    ```

5.  **Add a navigation link**

    Provide a translation label for the navigation menu in `src/lib/i18n/index.ts`, and add the link to the site navigation component (`Navbar.svelte`). This ensures users can discover the new page.

    ```typescript
    // src/lib/i18n/index.ts
    nav: {
      // ...
      gallery: "相冊", // Under zh
      gallery: "Gallery", // Under en
    }
    ```

6.  **Verify your changes**

    Run the type checking script. This catches potential issues early by validating TypeScript types and Svelte template syntax.

    ```bash
    npm run check
    ```

</Steps>
