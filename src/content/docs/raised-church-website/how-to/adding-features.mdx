## Adding a New Page

### Example: Adding a "Gallery" Page

#### Step 1: Define Contentful Content Type

In your Contentful space:

1. Content model → Add content type
2. Name: `gallery`
3. Fields:
   - `title` (Short text)
   - `description` (Short text)
   - `images` (Media, many)

#### Step 2: Enable Localization

1. Click each field
2. Enable "Localize this field"
3. Set up for both `zh-Hant-TW` and `en-US`

#### Step 3: Create Fallback Data

Create `src/lib/data/fallback-gallery.json`:

```json
{
  "title": "Gallery,"
  "description": "Church photos,"
  "images": [
    {
      "url": "https://placehold.co/400x300,"
      "alt": "Church building"
    }
  ]
}
```

#### Step 4: Define TypeScript Types

Edit `src/lib/types/contentful.ts`, add:

```typescript
export interface GalleryImage {
  url: string;
  alt: string;
}

export interface Gallery {
  title: string;
  description: string;
  images: GalleryImage[];
}

export interface ContentfulGalleryImage {
  fields: {
    url: string;
    altText: string;
  };
}

export interface ContentfulGallery {
  fields: {
    title: string;
    description: string;
    images?: ContentfulGalleryImage[];
  };
}
```

#### Step 5: Add Fetch Method to Repository

Edit `src/lib/server/content-repository.ts` to add the method to the interface:

```typescript
export interface ContentRepository {
  // ... existing methods
  fetchGallery(lang: Language | undefined): Promise<Gallery>;
}
```

Edit `src/lib/server/contentful-adapter.ts` to add the implementation:

```typescript
import fallbackGallery from "$lib/data/fallback-gallery.json";
import type { Gallery, ContentfulGallery } from "$lib/types/contentful";

export class ContentfulAdapter implements ContentRepository {
  // ... existing methods

  async fetchGallery(lang: Language | undefined): Promise<Gallery> {
    return this.withFallback(
      "gallery,"
      lang,
      async () => {
        const entries = await contentfulClient.getEntries({
          content_type: "gallery,"
          limit: 1,
          locale: getLocale(lang),
        });

        if (entries.items.length === 0) return fallbackGallery as Gallery;

        const fields = (entries.items[0] as any).fields as ContentfulGallery["fields"];
        const images = (fields.images || []).map((img) => ({
          url: getAssetUrl(img) || "https://placehold.co/400x300,"
          alt: img.fields.altText || "Gallery image,"
        }));

        return {
          title: fields.title,
          description: fields.description,
          images,
        };
      },
      async () => fallbackGallery as Gallery
    );
  }
}
```

Edit `src/lib/server/fallback-adapter.ts` to add the fallback implementation:

```typescript
export class FallbackAdapter implements ContentRepository {
  // ... existing methods
  async fetchGallery(lang: Language | undefined): Promise<Gallery> {
    return fallbackGallery as Gallery;
  }
}
```

#### Step 6: Create Route Directory

```bash
mkdir -p src/routes/[[lang]]/gallery
```

#### Step 7: Create Page Load Function

Create `src/routes/[[lang]]/gallery/+page.server.ts`:

```typescript
import { getContentRepository } from "$lib/server/content-repository";
import type { PageServerLoad } from "./$types";

export const load: PageServerLoad = async ({ params }) => {
  return await getContentRepository().fetchGallery(params.lang as "en" | "zh" | undefined);
};
```

Create `src/routes/[[lang]]/gallery/+page.svelte`:

## Adding a New Contentful Content Type

### Steps Summary

1. **Contentful Dashboard:**
   - Create content model
   - Define fields
   - Enable localization

2. **Source Code:**
   - Add TypeScript types (`src/lib/types/contentful.ts`)
   - Add fetch method (`src/lib/server/content-repository.ts` and adapters)
   - Create fallback JSON (`src/lib/data/fallback-*.json`)

3. **Use in Routes:**
   - Call fetch function in `+page.server.ts`
   - Use data in `+page.svelte`

## Adding Translations

### Add New Translation String

1. **Edit `src/lib/i18n/index.ts`:**

```typescript
export const translations = {
  zh: {
    pages: {
      gallery: {
        title: "相冊,"
        emptyMessage: "尚無照片,"
      }
    }
  },
  en: {
    pages: {
      gallery: {
        title: "Gallery,"
        emptyMessage: "No photos yet,"
      }
    }
  }
};
```

2. **Use in Component:**

```svelte
<script lang="ts">
  import { getTranslation, getLangFromParams } from "$lib/i18n";
  import { page } from "$app/state";
  
  let t = $derived(getTranslation(getLangFromParams(page.params)));
</script>

<h1>{t.pages.gallery.title}</h1>
<p>{t.pages.gallery.emptyMessage}</p>
```

### Key Naming Convention

Use nested object structure:
- `nav.*` - Navigation
- `pages.<pagename>.*` - Page-specific
- `common.*` - Shared across site
- `home.*` - Home page specific

## Common Patterns

### Fetching Paginated Data

1. Use `Pagination` component
2. Add URL parameter in `+page.server.ts`:

```typescript
export const load: PageServerLoad = async ({ params, url }) => {
  const page = parseInt(url.searchParams.get("page") || "1");
  const items = await fetchActivities(params.lang);
  const itemsPerPage = 6;
  const totalPages = Math.ceil(items.length / itemsPerPage);
  const paginated = items.slice(
    (page - 1) * itemsPerPage,
    page * itemsPerPage
  );
  return { paginated, currentPage: page, totalPages };
};
```

3. In component, update URL on page change:

```svelte
function handlePageChange(newPage: number) {
  page.goto(`?page=${newPage}`);
}
```

### Using Bilingual Content

```typescript
import { getBilingualContent } from "$lib/i18n";

const title = getBilingualContent(
  { zh: "標題," en: "Title" },
  lang,
  "Default Title"
);
```

### Responsive Grid

```scss
.gallery__grid {
  display: grid;
  grid-template-columns: repeat(autofill, minmax(300px, 1fr));

  @media (max-width: $breakpoint-tablet) {

  }

  @media (max-width: $breakpoint-mobile) {
    grid-template-columns: 1fr;
  }
}
```

## Deploying to Production

### If Adding Contentful Content Type

1. **Publish in Contentful first** (add at least one test entry)
2. **Push code to GitHub** with new page/component
3. **Vercel autodeploys** on push
4. **Verify at production URL** (raisedchurch.org)

### If Adding New Environment Variable

1. **Add to `.env.local`** for testing
2. **Commit code to GitHub**
3. **Add to Vercel project settings** (Settings → Environment Variables)
4. **Redeploy in Vercel dashboard** to pick up new env var
