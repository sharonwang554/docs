# Content Structure Overview

## Page-by-Page Content Breakdown

### 🖼️ Page Hero Banners (Various Pages)

**Contentful Content Type:** `pageHero`

**What can be edited:**

- The banner title and subtitle
- The background image for the page hero section
- Applies to pages: About, Activities, Events, Messages, Sharing, Offering, Training

**Content Structure:**

```
pageHero (multiple entries)
├── pageId (text: "about," "sharing," "activities," "events," "messages," "offering," "training")
├── title (text)
├── subtitle (text)
└── backgroundImage (file)
```

**Example:**

- Page ID: "sharing"
- Title: "分享園地"
- Subtitle: "弟兄姊妹的見證與分享"
- Background Image: sharing-banner.jpg

---

### 🏠 Home Page (`/`)

**Contentful Content Types:** `homePage`, `newsBanner`, `gatheringTime`, `churchNews`

**What can be edited:**

- Hero slider images (4 slides recommended)
- Each slide has an image and alt text
- A top-of-page news/announcement banner (optional, hidden when inactive)
- Upcoming events and announcements preview (autohides when no active items)
- Weekly gathering schedule entries

**Content Structure:**

```
homePage
└── heroSlides (array of references)
    └── heroSlide
        ├── image (file)
        └── altText (text)

newsBanner
├── message (text)         ← The announcement text
├── linkUrl (text)         ← Optional link URL
├── linkText (text)        ← Optional link label
└── isActive (boolean)     ← Show/hide the banner

gatheringTime (multiple entries)
├── name (text)
├── day (text)
├── time (text)
└── order (number)
```

### 📖 About Page (`/about`)

**Contentful Content Type:** `aboutPage`

**What can be edited:**

**Content Structure:**

```
aboutPage

        └── photo (file)
```

### 📢 News & Events Page (`/events`)

**Contentful Content Type:** `churchNews`

**What can be edited:**

- Item type (announcement vs event)
- Title and body text
- Event date and location
- Sign-up URL (for example, Google Form link)
- Sign-up deadline
- Cover image
- Active/inactive toggle

**Content Structure:**

```
churchNews (multiple entries)
├── title (text)
├── type (text: "announcement" or "event")
├── date (date)              ← For events
├── location (text)          ← For events
├── body (long text)
├── signUpUrl (text)         ← Optional external form link
├── signUpDeadline (date)    ← Optional
├── image (file)             ← Optional
└── isActive (boolean)       ← Show/hide
```

**Autohide behaviour:**
- When no active entries exist, the homepage teaser, nav link, and full page all hide automatically

**Examples:**

- Type: `event`, Title: "聖誕感恩晚宴," Date: 2026-12-25, Location: "教會大堂," signUpUrl: Google Form link
- Type: `announcement`, Title: "主日崇拜時間調整公告," body: "自四月份起..."

## Content Entry Limits

**Single Entry Pages** (only one entry needed):

- Home Page
- About Page
- Offering Page

**Multiple Entry Pages** (create as many as needed):

- Activities
- Church News (Events & Announcements)
- Sermons
- Sharings
- Training Resources

## Bilingual Content

For each content type, you can provide translations:

1. **Chinese (Traditional)** - `zh-Hant-TW` (default)
2. **English** - `en-US`

Switch between locales in the Contentful editor to fill in both languages.

## Content Workflow

1. **Create** - Draft new content
2. **Edit** - Modify existing content
3. **Publish** - Make content live on website
4. **Unpublish** - Remove from website (keeps in Contentful)
5. **Archive** - Remove completely

---

## Tips for Content Editors

### Images

- Recommended size for hero slides: 1400x700px
- Recommended size for activity images: 600x400px
- Recommended size for church news images: 800x450px (16:9)
- Recommended size for pastor photos: 200x200px
- Use JPG for photos, PNG for graphics
- Keep file sizes under 1 MB for faster loading

### Text

- Keep titles short and descriptive
- Use clear, simple language
- Break long text into paragraphs
- Proofread before publishing

### YouTube Videos

- Only enter the video ID, not the full URL
- Example: For `youtube.com/watch?v=ABC123`, enter `ABC123`

### Files

- Use PDF format for slides and newsletters
- Name files clearly (for example, "2025-12-01-`sermon-slides.pdf`")
- Keep file sizes reasonable (under 5 MB)

---

## Fallback Behavior

If content is not found in Contentful, the website will display default fallback data. This ensures the site always works, even during initial setup or if Contentful is temporarily unavailable.
