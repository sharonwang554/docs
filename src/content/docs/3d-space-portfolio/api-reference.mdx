This document provides a technical reference for the public APIs, component props, and configuration variables used throughout the 3D Space Portfolio.

## React Components

### `Earth`
The core 3D model rendered within the React Three Fiber canvas. Uses custom shaders for atmospheric scattering.

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `radius` | `number` | `2` | The base radius of the Earth sphere geometry. |
| `segments` | `number` | `64` | The resolution of the sphere (width and height segments). Higher values decrease performance. |
| `rotationSpeed` | `number` | `0.001` | The speed at which the Earth automatically rotates on its Y-axis per frame. |

### `SpaceBackground`
Procedurally generated starfield using Three.js `InstancedMesh`.

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `count` | `number` | `3000` | Total number of star instances to render. |
| `radius` | `number` | `50` | The minimum distance from the origin (0,0,0) where stars begin to spawn. |
| `opacity` | `number` | `0.8` | Base transparency of the star material. |

### `Section`
A standard DOM layout wrapper for portfolio content sections (e.g., About, Experience).

| Prop | Type | Default | Description |
| :--- | :--- | :--- | :--- |
| `id` | `string` | **Required** | The HTML ID used for anchor navigation and IntersectionObserver tracking. |
| `title` | `string` | `undefined` | Optional heading text injected at the top of the section. |
| `className` | `string` | `""` | Additional CSS classes applied to the root `<section>` element. |
| `children` | `ReactNode` | **Required** | The content to be rendered inside the section container. |

## Custom Hooks

### `useLanguage`
Consumes the global `LanguageContext`.

```typescript
const { t, language, toggleLanguage } = useLanguage();
```

- **`t`**: The current translation dictionary object.
- **`language`**: The active language string (`'en'` or `'zh'`).
- **`toggleLanguage`**: Function to switch between English and Chinese.

### `useScrollPosition`
Tracks the window's vertical scroll percentage, optimized with RequestAnimationFrame.

```typescript
const scrollY = useScrollPosition();
// Returns a normalized number between 0.0 (top) and 1.0 (bottom of document)
```

### `useMobileDetect`
Determines if the current client is a mobile device to apply WebGL performance downgrades or UI layout shifts.

```typescript
const { isMobile, isTablet } = useMobileDetect();
```

- **`isMobile`**: `true` if screen width < 768px.
- **`isTablet`**: `true` if screen width is between 768px and 1024px.

## CSS Custom Properties

These variables are globally accessible within the `:root` scope and can be overridden for theming.

| Variable Name | Default Value | Description |
| :--- | :--- | :--- |
| `--color-space-black` | `#050505` | Background color for the DOM overlay. |
| `--color-star-white` | `#f8f9fa` | Primary text color. |
| `--color-brand-accent` | `#4cc9f0` | Accent color for links, buttons, and highlights. |
| `--font-primary` | `'Inter', sans-serif` | Main typography stack. |
| `--font-mono` | `'Fira Code', monospace` | Font stack for code snippets and technical callouts. |
| `--z-canvas` | `0` | Z-index of the R3F WebGL `<canvas>`. |
| `--z-overlay` | `10` | Z-index of the standard HTML layout overlay. |

## Environment Variables

The Vite build pipeline utilizes `.env` files for build configuration and feature flags. Variables must be prefixed with `VITE_` to be exposed to the client bundle.

```bash
# .env
VITE_ENABLE_PERF_MONITOR=false
VITE_API_ENDPOINT=https://api.sharonwang.me
VITE_APP_VERSION=1.0.0
```

<Aside type="note">
  Do not place sensitive secrets (like private API keys) in the `.env` file, as they will be embedded directly into the frontend JavaScript bundle during the build step.
</Aside>
