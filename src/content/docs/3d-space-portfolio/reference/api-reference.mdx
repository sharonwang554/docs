## Context Providers

### LanguageContext

```typescript
interface LanguageContextType {
  currentLang: Language;
  toggleLanguage: () => void;
  t: (key: keyof UITranslations | SkillCategory) => string;
}

// Usage
const { currentLang, toggleLanguage, t } = useLanguage();
```

**Methods:**

- `toggleLanguage()`: Switches between 'en' and 'zh'
- `t(key)`: Returns translated string for given key
- `currentLang`: Current active language

**Features:**

- Automatic browser language detection
- localStorage persistence
- Document language attribute updates

## Utility Functions

### Language Detection

```typescript
const getInitialLanguage = (): Language => {
  const savedLang = localStorage.getItem("language");
  if (savedLang && (savedLang === "en" || savedLang === "zh")) {
    return savedLang as Language;
  }

  const browserLang = navigator.language.toLowerCase();
  return browserLang.startsWith("zh") ? "zh" : "en";
};
```
