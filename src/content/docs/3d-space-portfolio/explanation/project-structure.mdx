## Component Structure

Each component typically follows this structure:

```
ComponentName/
├── ComponentName.tsx         # Main component file
├── ComponentName.module.scss # Component-specific styles (SCSS Modules)
└── [additional files]       # Helper files (for example, shaders.ts for Earth)
```

## Key Architecture Patterns

### 1. Component Organization

- Components are organized by feature/section
- Each component has its own directory with styles
- Shared components are placed at the root of components/

### 2. Data Flow

- Static data defined in `lib/personalData.ts`
- Global state managed with Zustand stores
- Language context provides translation functions
- Props passed down for component-specific data

### 3. Styling Approach

- Global variables under styles/ folder.
- Responsive breakpoints in `styles/breakpoints.scss`
- Component-specific styles in local SCSS files
- BEM methodology for class naming

### 4. 3D Implementation

- Three.js integration via react-three-fiber
- Earth component with custom shaders
- Space background with optimized rendering
- Performance considerations for mobile devices

### 5. Internationalization

- Language toggle in header
- Translation strings in `lib/sectionTranslations.ts`
- Language context provides current language and translation function
- Components use translation function for text content
