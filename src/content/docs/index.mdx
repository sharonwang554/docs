<Aside type="tip" title="Documentation Quality & Methodology">
  All documentation on this site is prose-linted with [Vale.sh](https://vale.sh/) using the [Google Developer Documentation Style Guide](https://developers.google.com/style) and [Microsoft Writing Style Guide](https://learn.microsoft.com/en-us/style-guide/developer-content/) as baselines.
